## EasyDrv9(EDv9)는 무엇인가요?

EasyDrv9(万能驱动9, 만능드라이버9)는 Windows용 하드웨어 드라이버 검색·매칭·설치 작업에 사용되는 프로그램입니다. 이 저장소의 SoNG 버전은 EDv9 26v5 (9.0.2609.20009) 기준의 한국어 UI와 CLEAN OFFLINE / No-Residue 구성을 다룹니다.

## 이번 한국어판의 작업 범위

- 한국어 UI 현지화 및 긴 문구를 고려한 표시 개선
- 드라이버 검색·매칭·설치 작업 경로 유지
- 불필요한 브라우저 설정 변경 및 광고성 후처리 제거
- 관련된 외부 통신과 설치 후 잔여물 최소화
- 설정값 저장 기능 보완

기능별 검증 내용과 제한 사항은 이 저장소의 [README](../README.md), [프로젝트 상태](PROJECT_STATE.md)를 참고하세요.
